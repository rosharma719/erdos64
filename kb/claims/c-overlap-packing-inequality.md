# Overlap-packing inequality ν_g ≤ 2D_g + H

## Statement

For δ ≥ 3, odd girth g ≥ 5 and no C_{2g−2}: if ν_g is the maximum number of pairwise internally vertex-disjoint common paths (length ≥ 2) of distinct g-cycles, D_g the number of edges on no g-cycle and H the number of vertices of degree ≥ 4, then ν_g ≤ 2D_g + H; for cubic G, D_g ≥ ⌈ν_g/2⌉.

## Evidence

- `kb/runs/2026-11-17-handoff/run8/EG_NearDyadic_Run8/RESEARCH_NOTE.md#2`

## Caveats

Charging argument from the mixed-degree scale-escalation theorem; read on import, not refereed. Not a contradiction by itself: ν_g is not known to be large.
