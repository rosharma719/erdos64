# δ ≥ 3 + bounded degree + expansion do not force long cycles of nonzero residue

## Statement

For each odd prime p there are arbitrarily large cubic α-expanders (α = α(p)) in which every cycle of length > 5 has length ≡ 0 mod p: subdivide a cubic expander (each edge into a path of length p) and attach a pendant K4-with-subdivided-edge to each new vertex.

## Evidence

- `kb/runs/2026-11-16-dossier/passes/16_crux_sharpening.md#1`

## Caveats

The expansion estimate for pendant attachments is standard but only sketched. The example has bridges, so it does not bear on EG (minimal counterexamples are 2-edge-connected).
