# Universal ceiling on fractional dyadic resilience

## Statement

For a graph with n vertices, m edges and shortest dyadic cycle length q, the fractional resilience satisfies ρ(G) ≤ m(n−q)/(2nq); for cubic graphs ρ(G) ≤ 3(n−q)/(4q).
