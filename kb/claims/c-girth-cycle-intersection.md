# Two girth cycles sharing an edge meet in one path of length 2..h

## Statement

Let G have odd girth g = 2h+1. Two distinct g-cycles sharing an edge intersect in a single path of length t with 1 ≤ t ≤ h, and their union contains a cycle of length 2(g − t). If G has no C_{2g−2}, then 2 ≤ t ≤ h. For g = 2^k + 1 the excluded length 2g − 2 is 2^{k+1}.
