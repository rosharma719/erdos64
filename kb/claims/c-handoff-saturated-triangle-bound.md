# 8t < n for saturated triangle gadgets in bridgeless cubic dyadic-free graphs

## Statement

If a bridgeless cubic graph of order n with no dyadic cycle contains t disjoint saturated T-gadgets, then 8t < n. (Contract the gadgets; a perfect matching of the bridgeless cubic base gives a 2-factor; the weighted window theorem forces a dyadic cycle once half the vertices are marked.)

## Evidence

- `kb/runs/2026-11-17-handoff/handoff/Erdos_Gyarfas_Full_Research_Dossier.md#5.2`

## Caveats

Depends on the weighted window arithmetic and gadget disjointness arguments, which have not been refereed. No density lower bound on t is known, so it does not exclude counterexamples.
